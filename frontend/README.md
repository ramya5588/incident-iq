# IncidentIQ frontend

The React single-page app for IncidentIQ. See the
[main README](../README.md) for full setup, sign-in and configuration.

```bash
npm install
npm run dev      # http://localhost:5173, sends /api to the backend on :8080
npm test         # unit and component tests (Vitest, no backend needed)
npm run lint
npm run build    # production build into dist/
```

The backend must be running for the app to work.
